# Third-party notices

## Unitree Go2 model

The model, collision descriptions, meshes, and preview images originate from the Unitree Go2 directory of MuJoCo Menagerie, pinned to commit `367e3d9884401dcf6f9c27fa69f118992539039f`.

The original BSD-3-Clause license is retained in `upstream/unitree_go2/LICENSE`. `upstream/PROVENANCE.json` records the source file hashes. The workflow copies retain the same license and model provenance. Preserve these notices when redistributing the assets.

## Software dependencies

MuJoCo, Pinocchio, Coal, OSQP, NumPy, SciPy, Matplotlib, OpenUSD, and rendering dependencies are installed separately under their respective licenses. Isaac Sim is a separately installed runtime; the repository contains integration code and recorded evidence, not an Isaac Sim distribution.

## PACDM

The PACDM implementation (M. Dastranj and J. Mattila, arXiv:2609.11338) is included in `vendor/pacdm_original.py` and the corresponding workflow copies.
